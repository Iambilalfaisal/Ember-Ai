# Security

Customer data is encrypted in transit with TLS 1.2 or newer and at rest with AES-256.

Brightwave is hosted in Amazon Web Services data centres. Customers in the European Union can choose the Frankfurt region so their data stays in the EU.

Brightwave holds a SOC 2 Type II report, which is renewed every year. The report is available to customers under a non-disclosure agreement.

Single sign-on with SAML 2.0 and SCIM user provisioning are available on the Enterprise plan only.

Backups run every night and are kept for 35 days.
